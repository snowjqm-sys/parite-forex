Macro Score 模块 A

用简单、透明、可解释的宏观因子，把主观判断转成结构化 Direction / Range / Confidence。不预测精确点位。

生成新信号

选择品种、填入现价，勾选各宏观因子状态，系统按可解释权重计算总分与 bias。

信号列表

已生成的结构化信号，按时间倒序。

Event Scenario 模块 B

重大宏观事件前生成情景树，落地后更新 actual 自动计算 surprise 并匹配情景。

新增事件

录入 CPI / NFP / FOMC 等事件，含 consensus 与 previous。

事件列表

按时间倒序。事件落地后可填 actual 自动算 surprise。

Trade Planner 模块 C

把研究判断转成可讨论、能否决的交易卡（proposal）。不会自动下单，最终由人工在 CQG 执行。

生成交易卡

填写交易观点，生成 proposal，等待团队 approve 后再人工下单。

交易提案

Pending / Approved / Rejected 三态，由人工点击 approve 或 reject。

Risk Engine & Ops 模块 D

账户余额是比赛胜负手。监控 margin / drawdown / concentration / 单日亏损，以及 10 手/日赛制。

组合风险

风控红线来自配置文件（可调），正式赛前按 2026 Rules PDF 最终核验。账户权益默认模拟 $100,000，可到后端 risk-config 调整。

持仓管理

手工维护当前持仓（合约、数量、均价、现价）。

交易日志 Journal

每笔交易的假设 → 执行 → 结果 → 复盘，赛后沉淀为研究材料。

📦 数据备份

比赛数据存在服务器/云端，换浏览器、清缓存都不会丢。这里的导出文件是最后双保险—— 建议每天收盘后导出一份存到本地。
